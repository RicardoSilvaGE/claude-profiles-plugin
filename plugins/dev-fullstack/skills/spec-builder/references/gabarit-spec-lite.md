# Gabarit de la SPEC-lite (3 sections, ~30 lignes)

> Annexe de `spec-builder`, écrite le 11.11.2026 à partir de la ligne « 10 à 50 lignes » du tableau des étages. À ouvrir au deuxième étage, avant de rédiger. Fichier livré : `<racine-du-dépôt>/specs/YYYY-MM-DD-slug.md`, commité avec le code.

Trois sections, titres `##` à l'identique, sans numérotation, rien d'autre.

```markdown
# SPEC-lite — <Titre tâche>

> Projet : <projet> · Date : jj.mm.aaaa

## Objectif
<Une phrase, verbe d'action mesurable. Pas de « améliorer » sans chiffre.>

## Périmètre
- Dedans : <fichiers et comportements traités, chemins exacts>
- Dehors : <ce qui n'est PAS traité>

## Vérifications avant fin de tâche
- [ ] <Cas concret 1, sortie attendue précise>
- [ ] <Cas concret 2>
- [ ] Build et tests existants verts
```

Une information manquante s'écrit `À DÉFINIR — <explication>`, jamais inventée.
